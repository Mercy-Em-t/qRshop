# UC05: Manage Subscriptions

**Actor**: Admin
**Pre-condition**: Admin is logged into the Admin Panel.
**Post-condition**: Shop's subscription status is updated.

**Main Flow**:
1. Admin views the list of shops.
2. Admin selects a specific shop.
3. Admin changes the shop's plan from "Free" to "Paid".
4. System updates the `Subscriptions` table and enables advanced features for the shop.\n
