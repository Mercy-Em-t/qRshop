# UC04: Generate QR Codes

**Actor**: Shop Owner
**Pre-condition**: Shop Owner is logged into the dashboard.
**Post-condition**: QR codes are generated and available for download.

**Main Flow**:
1. Shop Owner navigates to the QR Generator section.
2. Shop Owner specifies the number of tables or enters table identifiers.
3. System generates unique URLs for each table (e.g., `?shop=12&table=5`).
4. System creates visual QR codes for these URLs.
5. Shop Owner downloads the QR codes for printing.\n
