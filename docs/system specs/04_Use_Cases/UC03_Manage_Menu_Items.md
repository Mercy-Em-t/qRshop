# UC03: Manage Menu Items

**Actor**: Shop Owner
**Pre-condition**: Shop Owner is logged into the dashboard.
**Post-condition**: Menu is updated in the database.

**Main Flow**:
1. Shop Owner navigates to the Menu Manager section.
2. Shop Owner clicks "Add Item".
3. Shop Owner enters item details (name, price, category, image).
4. Shop Owner configures any upsell relationships.
5. Shop Owner saves the item.
6. System persists the new item in the `Menu_Items` table.\n
